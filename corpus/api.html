Developer API limits

Category: developer

Northstar Notes is a fictional collaborative notebook service. This document is synthetic evaluation data, not a real commercial policy. Developer API limits applies to all eligible workspaces unless a signed contract explicitly overrides it. Administrators should share this guidance with workspace members when explaining service behavior.

The public API permits 120 requests per minute per workspace. This rule is published in the workspace handbook. Contact the workspace owner if you cannot locate the related setting. Support staff can explain the published rule but cannot silently change a signed agreement. Keep the workspace identifier ready when opening a ticket.

API clients receiving HTTP 429 must wait for the Retry-After header interval before retrying. The service dashboard records the relevant activity so workspace administrators can review it. The support team does not require users to disclose their passwords. Questions about an exception must be directed to support with the affected workspace identifier. This document intentionally omits future features and unpublished policies.
